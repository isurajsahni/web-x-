# Web{X} — Blog & Topical-Authority Plan (310+ ideas)

> Companion to `00-master-strategy.md` (§13 clusters) and `01-landing-pages.md` (the money pages each blog links up to).
> Every row is a **unique primary keyword**. Slugs use `/blog/{slug}` (recommended folder pattern — see master §25).
> Two parts: **(1) the reusable per-blog brief template**, **(2) ten worked exemplars** (one per cluster showing full depth), **(3) the full 310-idea inventory** in compact form. Expand any inventory row into a full brief using the template.
> Publish 8–12/month. Each article: answer-first intro (40–60 words), question H2s, one table/list of citable facts, author byline, 4–8 FAQs, and a link up to its money page.

Intent: **I**=Informational · **C**=Commercial-investigation · **T**=Transactional.

## PART 1 — Per-blog brief template (the 13 fields you asked for)

```
SEO Title:            <H1 on page — natural, keyword-led, benefit-driven>

Meta Description:     <140–155 chars — primary KW + differentiator + soft CTA>
Slug:                 /blog/<kebab-case-unique>
Primary Keyword:      <one>
Secondary Keywords:   <3–6 semantically related terms + entities>
Search Intent:        <Informational | Commercial | Transactional> + the query behind it
Outline:              H2/H3 structure, answer-first, question-based headings
FAQs:                 4–8 real questions (feed FAQPage schema, visible on page)
Schema Suggestions:   Article/BlogPosting + FAQPage (+ HowTo if steps) + BreadcrumbList
Internal Links:       up to the money page it supports + 2–4 sibling articles
External Links:       1–3 authoritative sources (Google docs, web.dev, platform docs, WCAG)
Call To Action:       matched to intent (consult for C/T, related-service/newsletter for I)
```

**NLP-entity discipline (apply to every article):** name the real entities — Webflow CMS, Framer, WordPress, Shopify, Core Web Vitals (LCP/INP/CLS), WCAG 2.2, GDPR, schema.org, headless CMS, design tokens, Figma Dev Mode, srcset, hreflang, 301 redirects, Lighthouse, CrUX. Precise entity use is how AI Overviews / Gemini / Perplexity map you to the topic.
