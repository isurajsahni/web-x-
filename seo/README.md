The plan for making Web{X} a globally authoritative website design & development agency.
Target markets: US, Canada, UK, Australia, Germany, France, Singapore, Netherlands, UAE, Ireland, New Zealand, Worldwide — **plus** a local Ludhiana/Punjab track (see `03-local-punjab.md`). Both run in parallel.

## How to use
1. Read `00` once — it sets the rules every page must follow.
2. Build money pages in batches (see the build sequence at the end of `00`). Never publish 150 pages at once.
3. Publish 8–12 blogs/month from `02`, each expanded with the template and linked into its cluster.
4. Two things to decide before scaling: the **`.com` domain** question and the **`/blog/{slug}` URL** migration (both in `00`).
